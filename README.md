# Balticar — Telegram-бот бронирования автомобилей

Готовый MVP для @BalticarKgdBot:
- каталог из 4 автомобилей;
- фотографии;
- автоматический расчёт тарифа;
- выбор дат;
- проверка пересечений бронирований;
- имя, телефон и комментарий клиента;
- заявка админу;
- кнопки подтверждения/отклонения;
- команда публикации кнопки бронирования в @Balticar_kgd;
- SQLite, без отдельного сайта.

## 1. Создать бота
В Telegram откройте @BotFather и создайте бота. Токен храните только в `.env`.

## 2. Узнать свой ADMIN_ID
Запустите бота, нажмите /start, затем /id. Полученное число внесите в `.env` как ADMIN_ID.

## 3. Настройка
Скопируйте `.env.example` в `.env` и заполните:
BOT_TOKEN=...
ADMIN_ID=...

## 4. Запуск локально
Python 3.12+:
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## 5. Кнопка в канале
Добавьте бота администратором канала @Balticar_kgd с правом публикации сообщений.
После запуска откройте бота и выполните /publish.
Бот опубликует пост с кнопкой «🚗 Забронировать».
