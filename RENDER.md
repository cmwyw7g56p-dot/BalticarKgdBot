# Balticar — Render deployment

This build runs as a Render Web Service using Telegram webhooks. It keeps the existing bot logic and falls back to polling when run locally without `RENDER_EXTERNAL_URL`.

## Render environment variables
Required:
- BOT_TOKEN
- ADMIN_ID

Optional/already configured in render.yaml:
- CHANNEL_USERNAME=@Balticar_kgd
- DB_PATH=data/balticar.sqlite3
- PENDING_HOLD_MINUTES=60
- TIMEZONE=Europe/Kaliningrad
- WEBHOOK_SECRET (generated by Render)

Render automatically supplies `RENDER_EXTERNAL_URL` and `PORT`.

## Important storage note
SQLite on a free Render Web Service is ephemeral. The bot can run for free, but SQLite data can be lost after a service restart/redeploy. For production bookings, move the booking table to a hosted database (for example, a free external database) before relying on it for long-term records.
